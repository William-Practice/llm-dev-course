# 软考软件设计师（中级）核心考点

## 考试结构
- 上午题：75 道选择题，150 分钟，满分 75 分，45 分及格
- 下午题：5 道问答题（数据流图、数据库设计、UML、算法、面向对象程序设计），150 分钟，45 分及格
- 两科必须同时通过（单科成绩不保留）

## 计算机组成
- 冯·诺依曼结构：运算器、控制器、存储器、输入设备、输出设备
- 原码/反码/补码：正数三者相同；负数补码 = 反码 + 1，计算机用补码运算
- 浮点数表示：阶码决定范围，尾数决定精度
- 总线：数据总线、地址总线、控制总线；地址总线宽度决定寻址空间（n 位 → 2^n 字节）

## 数据结构与算法
- 时间复杂度：快排平均 O(nlogn) 最坏 O(n²)；堆排序稳定 O(nlogn)；冒泡/插入/选择 O(n²)
- 二分查找 O(logn)，要求有序表
- 图的存储：邻接矩阵（O(n²) 空间）、邻接表（稀疏图省空间）
- 最小生成树：Prim（适合稠密图）、Kruskal（适合稀疏图）
- 最短路径：Dijkstra（非负权单源）、Floyd（多源）
- 哈夫曼编码：带权路径长度最小，用于无损压缩

## 操作系统
- 进程 vs 线程：进程是资源分配单位，线程是调度单位；同进程线程共享内存
- 调度算法：先来先服务（FCFS）、短作业优先（SJF）、时间片轮转、优先级
- 死锁四个必要条件：互斥、请求与保持、不可剥夺、循环等待
- 页面置换：FIFO（可能 Belady 异常）、LRU（最近最少使用）、OPT（最优，理论）
- 存储管理：分页（页表，解决外部碎片）、分段（逻辑单位）、段页式

## 数据库
- 三级模式：外模式（视图）、概念模式（表）、内模式（存储）
- 范式：1NF（属性不可分）、2NF（消除部分依赖）、3NF（消除传递依赖）、BCNF
- 事务 ACID：原子性、一致性、隔离性、持久性
- 并发问题：丢失更新、脏读、不可重复读、幻读；隔离级别从低到高：读未提交/读已提交/可重复读/串行化
- SQL：SELECT ... FROM ... WHERE ... GROUP BY ... HAVING ... ORDER BY 执行顺序

## 软件工程
- 生命周期模型：瀑布（顺序，需求稳定）、原型（需求不清）、螺旋（风险大）、敏捷（快速迭代）
- 内聚与耦合：高内聚低耦合是设计目标；内聚从低到高：偶然/逻辑/时间/过程/通信/顺序/功能
- 测试：单元测试（白盒，覆盖语句/判定/条件/路径）、集成测试、系统测试
- 黑盒测试方法：等价类划分、边界值分析、因果图

## 面向对象与 UML
- 三大特性：封装、继承、多态
- 设计模式（必考）：创建型（工厂、单例、建造者）、结构型（适配器、装饰、代理）、行为型（观察者、策略、模板方法）
- 单例模式：双重检查锁保证线程安全
- UML 图：用例图（需求）、类图（静态结构）、序列图（交互时序）、活动图（流程）、状态图
