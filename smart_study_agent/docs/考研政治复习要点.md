# 考研政治复习要点

## 考试结构
- 满分 100 分，考试时间 180 分钟
- 题型：单选 16 分（16题×1分）+ 多选 34 分（17题×2分）+ 分析题 50 分（5题×10分）
- 五个部分：马克思主义基本原理（24分）、毛泽东思想和中国特色社会主义理论体系概论（30分）、
  中国近现代史纲要（14分）、思想道德与法治（16分）、当代世界经济与政治 + 形势与政策（16分）

## 马克思主义基本原理
- 哲学基本问题：思维和存在的关系（物质与意识何者为第一性）
- 唯物论：物质决定意识，意识有能动作用；世界的物质统一性
- 辩证法三大规律：对立统一规律（核心）、质量互变规律、否定之否定规律
- 五对范畴：原因与结果、必然与偶然、可能与现实、现象与本质、内容与形式
- 认识论：实践是认识的基础；感性认识 → 理性认识 → 实践检验
- 历史唯物主义：社会存在决定社会意识；生产力与生产关系、经济基础与上层建筑两对矛盾

## 毛泽东思想与中国特色社会主义
- 毛泽东思想活的灵魂：实事求是、群众路线、独立自主
- 新民主主义革命总路线：无产阶级领导的、人民大众的、反帝反封建反官僚资本主义的革命
- 三大法宝：统一战线、武装斗争、党的建设
- 社会主义初级阶段基本路线：一个中心（经济建设）、两个基本点（四项基本原则、改革开放）
- 中国特色社会主义进入新时代：社会主要矛盾是人民日益增长的美好生活需要
  和不平衡不充分的发展之间的矛盾
- 新发展理念：创新、协调、绿色、开放、共享

## 中国近现代史纲要
- 1840 鸦片战争 → 中国开始沦为半殖民地半封建社会
- 1919 五四运动 → 新民主主义革命开端（无产阶级登上历史舞台）
- 1921 中共一大 → 中国共产党成立
- 1949 新中国成立 → 新民主主义革命胜利
- 1956 三大改造完成 → 社会主义制度确立
- 1978 十一届三中全会 → 改革开放

## 复习策略（按分值）
- 马原（24分）：理解为主，重点抓辩证法三大规律、认识论；多选题易失分
- 毛中特（30分）：分值最高，记忆时政结合，注意新表述（如"两个确立"）
- 史纲（14分）：时间线记忆，重大事件因果关系
- 思修法基（16分）：记忆为主，重点法治与道德部分
- 时政（16分）：11月前后复习，重点当年重大会议（如四中全会）
