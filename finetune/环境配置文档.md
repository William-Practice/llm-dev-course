脚本做的事（分 5 步）：

| 步骤 | 内容 | 实测耗时 |
|---|---|---|
| 1 | `python3 -m venv venv` 独立环境 | 5 秒 |
| 2 | `pip install torch`（CUDA 版） | **约 33 分钟** |
| 3 | transformers / datasets / peft / trl / bitsandbytes / modelscope 等 | 约 2 分钟 |

### 关键：第 2 步为什么慢

PyPI 上的 `torch` Linux wheel 会连带下载整套 nvidia CUDA 运行时，实测装了这些：

```
nvidia-cublas-13.1.1.3   nvidia-cudnn-cu13-9.24.0.43   nvidia-cusolver-12.0.4.66
nvidia-cusparse-12.6.3.3 nvidia-nccl-cu13-2.30.7       nvidia-cufft-12.0.0.61
nvidia-curand-10.4.0.35  nvidia-cuda-runtime-13.0.96   ... 共 17 个包
torch-2.14.0  triton-3.8.0
```

合计约 4.7 GB 下载 + 5.3 GB 安装后体积。**别以为卡死了**，用 `du -sh ~/.cache/pip` 能看到缓存持续增长。

### 第 4 步的依赖自动降级（正常现象）

装 LLaMA-Factory 前环境里是 transformers 5.17.0，装完后被它自动降到 5.6.0：

```
Uninstalling transformers-5.17.0 → Successfully installed transformers-5.6.0
Uninstalling datasets-5.0.1      → datasets-4.0.0

Uninstalling tokenizers-0.23.2   → tokenizers-0.22.2
```

**不要手动 pin 版本**去对抗它 —— LLaMA-Factory 自己知道要什么版本，让它解析就不会有兼容问题。

## 6. 常见报错与解决（加分项 · 都是本次真踩的）

### ① hf-mirror 下大文件只有 329 B/s

现象：`hf-mirror.com` 下 `model.safetensors` 实测 329 B/s，下 3GB 要 2.5 小时。
原因：镜像对大文件限速/需要不同处理。
解决：换魔搭直连。实测对比：

```bash
# 测速（各下 20MB）
curl -s -r 0-20971520 -o /dev/null -w "%{speed_download}\n" https://hf-mirror.com/Qwen/Qwen2.5-1.5B-Instruct/resolve/main/model.safetensors
# → 329 B/s
curl -sL -r 0-20971520 -o /dev/null -w "%{speed_download}\n" https://www.modelscope.cn/models/Qwen/Qwen2.5-1.5B-Instruct/resolve/master/model.safetensors
# → 2133362 B/s   ← 快 6000 倍
```

**教训：下模型前先测速，别默认 hf-mirror 就行。**

### ② 用 `du -sh` 的 MB 数判断完整性会误判

现象：`du` 显示 2944.44 MB，`stat` 显示 3,087,467,144 字节，我按 MB 换算以为"少了 7KB"，白折腾一轮续传。
原因：MB 显示是 1024 进制四舍五入，不是精确字节数。
解决：**只认 sha256**。`curl -C -` 续传时如果本地已完整，下载 0 字节是对的，别慌。

```bash
stat -c%s model.safetensors    # 精确字节数
sha256sum model.safetensors    # 与模型库记录比对
```

### ③ `torch.cuda.is_available()` 报 NumPy 缺失警告

```
UserWarning: Failed to initialize NumPy: No module named 'numpy'
```
原因：torch 装完但没自动带 numpy。
解决：`pip install numpy`（已含在 prepare_env.sh 第 3 步）。**只是警告，不影响 CUDA 判断**。

### ④ 手动 pin transformers 版本反而更糟

现象：先装了 transformers 5.17.0，本以为要手动降到 4.5x 才兼容 LLaMA-Factory。
解决：不用管。`pip install llamafactory` 会自行把版本解析到它能用的组合（5.6.0）。
**手动 pin 反而容易和 peft/trl/tokenizers 的版本约束打架。**

### ⑤ 4GB 显存能不能训

结论：**能，但必须 4bit QLoRA**。

- 显存 3.68 GB 可用，全参微调 / bf16 LoRA 都放不下 1.5B 模型
- 可行配置：`quantization_bit: 4` + `lora_rank: 8` + `per_device_train_batch_size: 1`
  + `gradient_accumulation_steps: 8` + `gradient_checkpointing: true` + `cutoff_len: 512`
- 3B 模型在本机 4GB 上基本没戏，要训 3B 得走魔搭云端 GPU
